# HackUNCP

The websites for HackUNCP, UNC Pembroke's 24-hour hackathon. Each site has its own folder.

| Folder | What's in it | Status |
|---|---|---|
| [`2025-2026/`](2025-2026/) | The earlier site, with the 2025 and 2026 events | Kept for reference, not published |
| [`2027/`](2027/) | The HackUNCP 2027 site | **Live** at https://hackuncp.github.io/ |

Only `2027/` is published. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) builds that folder on every push to `main`.

To work on the site, see the [2027 README](2027/README.md).
